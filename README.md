# فريدة جاليري | Farida Gallery

موقع بسيط (ملف `index.html` واحد + فولدر `images`).

## تعديل المنتجات

افتح `index.html` وعدّل مصفوفة `PRODUCTS`:

```js
{ name:"اسم المنتج", price:"250 جنيه", desc:"وصف قصير", img:"images/1.jpg", cat:"تصنيف 1" }
```

## الصور

- حط الصور في فولدر `images/`
- الأفضل تكون بنسبة 4:5 (مثلاً 800×1000) وحجم أقل من 300 كيلوبايت
- لو الصورة مش موجودة هيظهر مربع بوردو بدالها
